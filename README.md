# office365

DocSlide: a proof of concept for template-based documents and presentations. Pick a template, edit it, then export to DOCX, PPTX or PDF. Live at [office365-nine.vercel.app](https://office365-nine.vercel.app).

> The HTML to DOCX/PPTX export work from this project continues in [ooxify](https://github.com/salalaslam/ooxify), a library and CLI that turns HTML into editable PowerPoint and Word files.
